# Yaron Fanger Portfolio

A Flutter implementation of the portfolio screen included in `3.zip`.

## Open and run

1. Open this folder in Android Studio.
2. Allow Gradle sync to finish.
3. Select an Android emulator or connected phone and press **Run**.

You can also run it from this folder with:

```bash
flutter pub get
flutter run
```

The original archive contained only `lib/main.dart` and referenced a missing portrait asset. The header now uses a built-in Flutter placeholder portrait so the project runs without extra files. The screen preview is saved in `screenshots/portfolio_preview.png`.
